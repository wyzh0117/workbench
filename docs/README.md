# docs

- [`feature-history/`](./feature-history/README.md) — **Feature Update Manual**:
  the natural-language product history for every public release (one file per
  version plus the rolling `UNRELEASED.md`). Start here when you want to know
  which version introduced a capability.

Everything else that used to live here was internal development material
(acceptance reports, release playbooks, closure records). It is deliberately
not part of this repository.
