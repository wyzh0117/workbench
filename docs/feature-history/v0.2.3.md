## 这个版本用户能做什么新事情？

- **把手头已有的 Markdown 文件（或整个文件夹）搬进课程，而且搬之前看得见计划。** 导入 Markdown、文件和文件夹时会给出一个**可见的映射计划**；对选中的 Markdown，你可以在确认之前先看它引用了哪些本地图片。缺失的或不安全的引用会被报告出来，而 **Workbench 不会去抓取远程内容**——不会因为导入一个 md 就替你去下载别人服务器上的图。
- **把导入的课追加到已有的项目里，并指定放在哪个阶段 / 哪一课。** 整个导入是**一次可撤销的操作**：Undo / Redo 一次处理完整批导入，不用一条一条退。
- **同一份文件不会被不小心导两遍。** 重复检测用的是来源文件的校验和（checksum）：内容相同的 Markdown 默认会被跳过，而**你在 Workbench 里已经做过的编辑不会被覆盖回去**。来源文件保持原位、字节不变。
- **正文里的 Markdown 按语义显示**，预览里也一样：标题、列表、表格、代码、引用、粗体这些是按含义渲染的，不是一屏源代码文本。
- **文件浏览器里可以直接预览支持的本地文件，而不必先把它变成课程的一部分**——只是看一眼，不导入。
- **AI 设置把三种请求协议当成三件不同的事**：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 各自按自己的请求格式处理，不再共用一套假设。同时把「怎么用 AI」和「怎么连 AI」分开了：使用界面和连接管理界面不再混在一起，连接管理更清楚。
- **原生支持用 ChatGPT 订阅登录**（Sign in with ChatGPT），凭据按账户作用域保存，并且有会话刷新。浏览器方式运行时仍然使用 API 连接。
- **媒体预览更好用**：静态图片 / GIF 海报（poster），以及受控的视频播放——播放结束 / 离开时会做资源清理。

## 哪些操作方式发生了变化？

- **导入多了一道「看计划」的闸**：先扫所选目录 → 给出映射计划 → 你可以 review 选中 Markdown 的图片依赖 → 才确认写入。远程 / 危险 href 不会被自动抓取。
- **重复导入的默认行为是「跳过」**：同校验和的来源默认不重复导入，你已经编辑过的内容保留。
- **区块控件更紧凑**（Release 正文：more compact block controls），小屏时工具栏会**换行**而不是被裁切。
- **分页的交互行为更清楚**（Release 正文：clearer pagination behavior）；退出分页编辑再进入、切换 Flow / Grid 后重新进入，页面与栅格位置会保留（验收报告 preview7 / 8，来自隔离 QA fixture）。
- **移动区块之后文字仍然选得回来**（Release 正文：text selection recovery after moving blocks）；实测包括 preview6 拖动后重新选字通过，以及 preview8 里用 Escape 取消 click-move 之后位置不变、正文仍可选字。
- **AI 的设置项重组**：使用 AI 的界面和配置连接的界面分开，连接管理独立；设置里三个协议项分别可见，新建连接的表单可以取消且取消后不持久化、服务商列表保留。设置入口在顶部，模型管理入口只有一个，课程地图仍然可达。
- **订阅登录只在原生应用里有**：Sign in with ChatGPT 走的是原生 Tauri 回调路径；**浏览器运行仍然使用 API 连接**，没有这条路径。

## 哪些旧问题被修复？

- **视频首帧缩略图空白 / 迟到 Blob 残留**：首帧解码遇到透明帧时的重试，以及迟到的 Blob 清理，都有自动化通过（验收报告：首帧改动早期出现的 388/1 失败被查明是**旧测试替身缺少 rVFC / canvas pixel API** 造成的，更新替身后修复；视频首帧与文件浏览器的定向测试 9/9）。
- **窄窗口下工具栏按钮被挤掉**：preview8 验证窄屏工具栏全部按钮换行、说明水平显示且未遮挡；窄窗时文件页改为单列，避免文件名在窄列里竖排。
- **导入 / 追加破坏项目身份或既有引用**：来源校验和与持久来源记录保护重复检测；追加需要保留项目身份、现有正文 / 分页 / 素材引用，并有自动化回归保护。
- **导入边界的安全问题**：导入边界再次以源 hash、后端解析和路径授权校验依赖；中间符号链接越界会被拒绝（Rust 定向回归 1/1）。
- **一批测试替身与脚本问题**：QA 快照里的临时诊断 overlay / script 已从发布源码删除，正式 Universal app / DMG 是在删除之后重新构建并验证的。
- **一项被查明「不是产品缺陷」**：目录选择时「单击只触发 hover、没有选中目录」的现象，经键盘明确选择目录后扫描目标目录正常，被判定为自动化操作方式的问题，**不是产品路径缺陷**——所以这里不记为修复。

自动化侧最终源码完整结果：`deno task test` **389/389**、`cargo test` **95/95**、`deno task check` 与 `cargo fmt --check` 通过。定向证据：Deno 扫描测试 9/9、导入事务 11/11（含故障注入）、Rust 导入 5/5、中间符号链接拒绝 1/1、AI 设置定向测试 29/29。

## 兼容性或迁移变化

- **没有记录项目数据的迁移或格式破坏性变更。** 记录里没有要求旧项目做任何转换。
- **平台能力差异是明确的使用边界**：Sign in with ChatGPT 订阅路径只在原生 Tauri 运行时可用；**浏览器运行时继续使用 API 连接**，不支持这条原生回调路径。
- **同一份导出在不同实现下结果不同（用户需要知道）**：Deno / 服务层的 PDF 输出目前**省略行内图片**并给出 `pdf_inline_images_omitted` warning；而**原生 PDF 实测包含行内图片**。PPTX 会把复杂的 Markdown 表格和嵌套列表**简化**处理并为此发出 warning。
- **预览能力取决于格式和当前 WebView 的能力**：不支持的文档格式仍然作为参考文件提供，不保证内嵌预览。
- `v0.2.3` 的 tag 与两项资产**保持冻结不可变**；`v0.2.2` 及更早的 tags / assets 未改动。公开发布的唯一路径仍是推送新的 `v*` tag，其版本需与 `src-tauri/tauri.conf.json` 一致。

## 已知限制

Release 正文的「Notes」小节把这些限制写在面向用户的位置，本手册原样保留：

- **GIF 动画播放没有在这台机器上通过**：静态 GIF 海报可用，但**动画 GIF 的放大播放没有在实测的 macOS WKWebView 中观察到**——模态里的图片，以及用同一份已验证的 GIF 字节独立构建的 `<img>`，在连续 2.65 秒里都只显示第一帧红色画面。这在**那个 WebView 环境下仍未解决**；GIF 的字节本身是好的（487B、MIME `image/gif`、GIF89a、SHA-256 与 fixture 一致，能加载为 160×90），**不能据此说源文件损坏**。
- **精确 1024 像素布局、系统文字缩放、指针拖动中途取消未验证**。验收报告还补了一句：preview3 / preview8 的观察没有记录实际 CSS 宽度。
- **自动化测试只使用本地协议 / 鉴权替身**：它们**没有验证真实的 SIWC 登录、没有对真实账户做 token 刷新、也没有发起过真实 Provider 的模型请求**。使用连接之前请你先自行授权自己的连接。三种 API 协议的请求与部分订阅会话行为是通过自动化 / 本地替身验证的；**不得把本地替身描述为在线账户验收**。这是从 v0.1.0 到 v0.2.3 一直没有被解决的同一项限制。
- **导出侧的已知降级**：Deno / 服务层 PDF 省略行内图片（`pdf_inline_images_omitted` warning，原生 PDF 已验证含图片）；PPTX 对复杂 Markdown 表格与嵌套列表做简化并产生 warning。
- **公开包是 ad-hoc 签名、没有 `TeamIdentifier`、没有做 Apple 公证**。在构建出来的包上 `spctl --assess --type execute` 返回 **rejected**；首次打开可能需要你在「隐私与安全性」里手动放行。本构建**没有** Developer ID 签名与公证可用——分发状态是 **PARTIAL**。
- **放行之后的首次启动未实测**：实测到的是匿名下载公开 DMG 与 sidecar、SHA-256 一致、`hdiutil verify` 通过、包内版本 0.2.3、架构含 x86_64 与 arm64 这些「下载与包本身」的事实；人工放行之后的那一次启动没有记录为已实测。
- **原生 GUI 观察来自隔离的 preview4 / 6 / 7 / 8 / 9 QA 快照，没有在正式发布的包上重跑整套 GUI 验收**。正式发布包只做过一次「无诊断轻抽检」（确认正文聚焦行显示自己的 +/⋯ 控件、顶部设置进入 AI 模型管理、课程地图可达）。验收报告原话：这些快照**不能替代完整的正式包 GUI 复测**。
- **若干验收项只到「部分」为止**（验收报告矩阵）：子目录排除的独立原生证据不足；向既有项目**追加文件夹**（而非文件）未覆盖；原生失败重试与打开失败的边界未覆盖；DOCX 与其他不支持格式未逐类原生走查。
- **整体验收状态为 PARTIAL**：发布这个事实**不代表** GIF 动画、在线 SIWC / Provider、精确字体缩放或指针拖动取消已经验收。
