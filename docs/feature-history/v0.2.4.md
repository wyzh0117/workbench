## 这个版本用户能做什么新事情？

- **打开一个文件夹时，Workbench 先看懂它再说话。** 选到的目录里如果真有可用的 `project.json`，就直接开；如果那个文件坏掉、太旧、太新或者根本不是课程文件，提示会说出真正的问题（哪一个字段、文件在哪里），而不是笼统的「没有找到 project.json」。想推倒重来时，「重新导入」会先把原来那份留成备份。
- **导入一个文件夹，里面图片和视频会被一起收进素材库。** 递归往下找，只收画面类素材（图片、视频），文档不会被悄悄当成素材卷进来；同一个内容按校验和去重，同名不同内容的两个文件各自保留。映射预览仍然只列目录下面第一层，源目录一个字节都不动。
- **一次可以选好多个文件加进素材库。** 多选、拖一整个文件夹都可以；其中一个文件读不出来也不会取消其他文件，结果会一份一份报清楚（成功几个、重复几个、失败几个、跳过几个），整个批次撤销时也是一步撤掉。
- **在素材库里改名字，磁盘上那个文件真的跟着改名。** 课程里所有引用它的位置同步更新，素材编号、校验和、引用关系都不变；撤销会把文件改回原名，重做再改回去，项目记录和磁盘始终一致。
- **AI 连接可以自己配。** 填服务商 ID、显示名、Base URL、协议（OpenAI Chat Completions / OpenAI Responses / Anthropic Messages 三选一）、只写不读的 API Key，然后向服务商真实读取模型清单再挑；清单拿不到时也能手写模型 ID。不再预置任何服务商模板。
- **ChatGPT 订阅登录的每一步都会告诉你卡在哪。** 已登录但没授权 plan usage、模型清单请求失败、账户没有可用模型、令牌刷新失败、模型能选但推理失败——这几种情况各有各的说法，不再合并成一句「AI 配置失败」。
- **媒体库的卡片终于以画面为主。** 缩略图占大块、4:3 固定比例、中性底色，名称和「类型 · 大小 · 用量」在下方，操作排成一行。PNG / JPG / WebP 显示真实缩略图（PNG 不再是一片空白），GIF 和视频取第一帧。
- **点卡片可以放大看。** 图片点开即放大；GIF 放大后开始播放；视频放大时停在首帧、中间有播放按钮；关闭后回到静态首帧。关闭方式有三种：点背景、点 ×、按 Esc。

## 哪些操作方式发生了变化？

- **正文编辑器不再有 B / I / S 按钮，也没有「看 Markdown 源码」开关。** 直接输入 `**粗体**`、`# 标题`、`> 引用`、`- 列表`、`` `代码` `` 这类写法，它会自动变成真正的富文本样式，符号本身消失，光标留在你刚才打字的位置。
- **区块工具条默认看不见。** 平时只剩干净的正文；鼠标移到区块上、选中它、或键盘焦点落在里面时，操作条才浮出来——它是浮层，不会把下面的内容顶下去。区块属性也走同一套浮层。
- **Grid 排版恢复左键 / 右键的直接用法。** 左键点一块还没放的正文，它落到第一个可用格子；左键点已放好的区块进入移动状态，再点高亮格子就放下；右键把区块移出画布（可撤销）；Esc 或点画布空白处取消移动。选中文字往外拖不会被误判成移动命令。
- **分页画布有明确的两种状态。** 没启用分页时不再出现「输出分区」编辑器；启用后才有页签和相关页面/分区控制。「退出分页编辑」只是离开编辑状态，页面结构、页面顺序、内容位置全部原样保留，再进来还在原来那一页。同一个页面不再出现两个重复标题。
- **素材重命名变成了直接改文件名：** 点「✎ 重命名」就地输入新名，按回车提交；名字留空会直接说「素材名称不能为空」，改坏了或撞名会说明原因，并且按 Esc 等于什么都没做。
- **保存 AI 连接被拒绝时不再清空表单**，并且会指名是哪个字段有问题；Base URL 缺协议、无法解析、没有主机名或者把账号密码写进网址，都会在发请求之前就被拦下。
- **换 Base URL 时会先问你是否愿意把密钥带过去**（v0.2.2 起的行为保留），并且只有你确认之后才会真的发送。

## 哪些旧问题被修复？

- PNG 素材在媒体库里显示空白缩略图。
- 导入普通文件夹时误报「没有 project.json」，把可用项目挡在门外。
- 输入 Markdown 语法后光标乱跳、输入法（IME）被打断。
- 撤销一次自动转换需要按两次撤销（多出来的那一步其实什么都没改）。
- 区块移动完成后画面上残留「正在移动」横幅和「放这里」目标，误点会再移动一次。
- 重命名素材时一次回车会提交两次，把成功提示替换成「素材名称没有变化」并留下一条空撤销步骤。
- 撤销重命名后，项目里还写着那个已经不存在的旧文件名（磁盘与记录不一致）。
- 重命名留空时静默失败，用户不知道到底改没改。
- 保存 AI 连接被拒绝时，刚填的表单内容全被丢掉；Base URL 少写 `https://` 或把账号密码写进网址时没有任何提示就保存失败。
- 放大的媒体预览按 Esc 关不掉；关闭后 GIF / 视频可能在已经看不见的界面后面继续播放。
- 同一个页面重复出现两个标题。

## 兼容性或迁移变化

- **素材重命名的语义变了（有意为之）**：以前只改显示名，现在会改磁盘上托管文件的真实名字。旧项目里的素材记录会照常工作，不需要迁移。
- **AI 服务商配置不再有预设模板**：升级后设置页是空的，需要自己填一条连接。已有连接、钥匙串里的密钥和协议字段（v0.2.3 引入）保持不变，本轮没有改变存储结构。
- **重开项目时会做一次结构修复**（补齐缺失集合、修正旧的状态维度赋值）。这份修复在首次打开时是待保存状态，所以保存状态标记会短暂显示「未保存」，直到第一次自动保存——这是有意的，不做掩盖。
- API Key 仍然只存在系统钥匙串里，绝不写进 `project.json`、Canonical、导出包、诊断信息或功能历史。
- 除上述两项外，本版没有破坏性的项目字段变化；`v0.2.3` 的项目文件可以直接被本版打开。

## 已知限制

- **原生界面的指针验收没有由自动化环境完成。** 收口这一轮的环境无法向 macOS 窗口发送真实点击（AppleScript 系统事件超时 `-1712`），也无法截图（`could not create image from display`）。所有行为改动都是在**与安装包逐字节相同的前端**上真实操作验证的（本项目没有前端构建步骤），另有针对真实磁盘文件的自动化测试；但原生打开面板的多选、窗口内的真实指针拖放、放大后 GIF 的播放、真实输入法，仍需要人来确认一次。
- **真实在线 AI 仍未验收**：没有在线 Sign in with ChatGPT 登录、没有真实账户的 token 刷新、没有真实服务商的推理调用（该环境到 `api.openai.com` 的请求 60 秒超时）。订阅凭据确实存在于 macOS 钥匙串，验证过程只读取元数据、未打印任何密钥。自动化测试只用本地协议 / 鉴权替身。
- 本版安装包为 **ad-hoc 签名，没有 TeamIdentifier、没有 Developer ID 签名、没有 Apple 公证**；`spctl --assess --type execute` 为 `rejected`，首次打开需要手动过 Gatekeeper，方式取决于 macOS 版本（见 Release 页面与 `README.md`）。Apple Developer ID 签名与公证是单独的分发阻碍。
- **精确 1024 像素布局、系统文字缩放、指针拖动中途取消未验证。**
- **Deno / 服务层 PDF 输出省略行内图片**并给出 `pdf_inline_images_omitted` warning（原生 PDF 已验证含图片）；**PPTX 简化复杂 Markdown 表格与嵌套列表**并为此发出 warning。
- **PNG / JPG 位图输出与复杂长图海报系统为明确的非目标。**
- **Windows / Linux 不支持。**
- 撤销批量导入只会把项目恢复原样，`assets/` 目录下留下的文件不会被自动删除——这是刻意的（Workbench 不删自己没创建的磁盘文件）。
- 打开旧项目后短时的「未保存」标记见上一节；要做成「这次加载到底改没改」的诚实判定，需要服务层新增一个信号，不在本轮范围内。
