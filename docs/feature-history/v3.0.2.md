## 这个版本用户能做什么新事情？

**没有新的功能、新的入口或新的操作**——这一版解决的是「同一个软件看起来像好几个软件」的问题。用户能感知到的是界面变整齐、变可读了：

- **全站控件是同一套规格。** 按钮（主按钮品牌绿 `#14725f`）、输入（H32 / R12）、标签页（统一 39px）、分段控件（R12 灰容器 + R8 白片）、卡片（R16）、模态（R28）、徽章（一套 pill）、状态点（8px 正圆）在每个页面都是同一副面孔（对照证据：[课程表前](../reports/evidence/ui-redesign-2026-10-24/01-before-overview.png) / [后](../reports/evidence/ui-redesign-2026-10-24/02-after-overview.png)）。
- **文字终于读得清了。** 8–10.5px 的中文不可读字号**全部清零**（此前 10px 一处就有 69 处用法），字阶从 24 种收敛到 **9 档**（11–28px，11px 硬下限）；圆角从 16 种收敛到 **6 档**（4 / 8 / 12 / 16 / 20 + pill）。
- **页头行动组一行放得下。** 主行动回到首位、单行右对齐，不再被三个次级按钮挤到第二行（[课程地图前](../reports/evidence/ui-redesign-2026-10-24/03-before-course-map.png) / [后](../reports/evidence/ui-redesign-2026-10-24/04-after-course-map.png)）。
- **状态列一眼扫得完。** 「徽章 + ▶ 三角文本 + 裸灰文本」三套写法统一为同一个 chip 家族；行操作图标钮也统一了规格。
- **设置页知道自己在哪。** 子导航有了真正的 active 态：状态驱动高亮，点击锚点后指示器跟随目标分区（[设置页子导航](../reports/evidence/ui-redesign-2026-10-24/07-after-settings-nav.png)）。
- **加载过程看得出来。** spinner / skeleton 统一了加载与占位表达，左栏「等待加载」不再断行（[工作台编辑前](../reports/evidence/ui-redesign-2026-10-24/08-before-editor.png) / [后](../reports/evidence/ui-redesign-2026-10-24/09-after-editor.png)）。
- **颜色不再打架。** 脱轨的紫色强调族 **26 处 → 0**、冷灰中性族 **42 处 → 0**，全部归入品牌绿与暖中性；字面量阴影 16 种 → 0（统一 4 级全绿调）；硬编码色 **341 → 31**（其中 17 个是 token 定义、13 个是测试逐字锁定的字面量）。奇数间距野值 347 处 → 10 处（余下 10 处是刻意保留的 1px 发丝隙）。

## 哪些操作方式发生了变化？

**没有。** 本版**没有任何交互流程变化**：按钮、入口、点击行为、键盘操作、导出与 AI 流程都与 v3.0.1 逐字一致（256 条文案锁定、179 条 DOM 结构锁定原样通过）。变化只有**视觉规格与信息层级**：

- **旧**：页头主行动被换行、状态有三套表达、同一个控件在不同页面长得不一样。
  **新**：主次行动的视觉权重理顺（主行动首位单行），状态信息收敛为一种表达，同一控件全站同貌——**看的方式变了，用的方式没变**。
- 发布页的步骤序号不再写两遍（`1. 选择输出范围` 与 `01` 徽章双写去重，[发布页前](../reports/evidence/ui-redesign-2026-10-24/05-before-publish.png) / [后](../reports/evidence/ui-redesign-2026-10-24/06-after-publish.png)）；步骤徽章与设置页绿色圆徽章同型。
- 文件浏览页的第二个绿色主按钮（与空态内按钮做同一件事）降级为次级，主行动只剩一处，层级清晰。
- emoji 与几何字符图标归入同一族（9 个图标字符），不再一半 emoji 一半几何字符。

## 哪些旧问题被修复？

- **可读性硬伤**：8–10px 中文字号在真实渲染里几乎不可读，现已清零（11px 硬下限，字阶 24 种 → 9 档）。
- **断行 bug**：左栏「待加载」徽章因容器过窄断成「待加 / 载」，现已不折行。
- **图标混用**：`📎🖼🔗📝⚠` 等 emoji 与 `▤✎⚙✦` 等几何字符混排（跨平台渲染不稳、风格冲突），现归入同一字符族。
- **脱轨色**：紫色强调族（正文块聚焦、进度条绿→紫渐变、AI 选中态、网格 / 启动页 / 看板 hover）与冷灰中性族（徽章、面包屑分隔符、拖拽手柄等）与绿色主色、暖中性 token 打架，现已清零。
- **同名组件多写法**：`.tab` 三种高度、`.badge` 两套配色、四种空态写法、三套分段 / 筛选选中态、两套统计数字字号，现已各归一。
- **信息重复 / 冗余**：发布步骤序号双写、文件页双主 CTA、状态三套表达，已去重归一。
- **导航不可辨**：设置子导航此前选中项与其它项几乎无差别，现已可辨。
- **加载态随意**：spinner / skeleton 成为统一表达，替代散落的等待文字。

## 兼容性或迁移变化

- **无 schema 变化、无数据迁移。** 课程文件、项目配置、`providers.json`、系统钥匙串里的凭据都不受影响；旧项目、旧配置照常打开、照常使用。本版不改任何数据格式与导出格式。
- **功能不变量逐字保留，未为美观改动**：分页区块尺寸、三栏栏宽（左 228 / 右 286px）、窄屏断点（`@media (max-width: 1150px)`）、`--control-height: 35px` 等被测试逐字锁定的功能面原样（完整清单见[测试契约](../research/ui-test-contract-inventory.md) §1.1 / §1.2）。
- **版本号 3.0.2 已同步写入** `src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`。
- **仓库状态（非用户可见功能）**：`workbench-3.0.0` 分支已合并进 `main` 并删除，本地与远端只保留 `main`。v3.0.1 及更早的用户可见能力仍归属各自版本。

## 已知限制

- **图标仍是字符，不是图标库。** 本版只做了 emoji → 同族几何字符的最小替换；未引入 Lucide / 内联 SVG 等图标库（审计 §D「不做」第 6 条，图标库大规模引入超范围且动测试锁定的文本节点）。
- **深色主题未做。** 本次仅浅色主题（`color-scheme: light`，审计 §D「不做」第 1 条）。
- **1px 发丝隙保留。** 0.5px 发丝描边依赖设备像素比，本次不做，沿用 1px（审计 §D「不做」第 2 条）；间距里保留的 10 处奇数野值就是刻意的 1px 发丝隙。
- **字体家族未更换、未引入品牌资产 / 插画**（审计 §D「不做」第 3、4 条：问题在字阶不在字族；不引入 DeepSeek 品牌资产）。
- **审计清单里的「`需要配图` 孤立浮文 → 空态卡」未执行（产品判断）。** 经浏览器实测，该文本是 `article.block.block-paragraph` 里的**用户正文段落**，不是 UI 空态；给它包卡片等于篡改正文呈现语义，且与测试锁「区块无白卡容器」冲突。本版改为统一真正的占位 / 空态与加载态。
- **状态点取 8px 正圆**（与已认可的参照规格一致）；任务简报的 6px、改造前代码的 7px 与之不一致，本版取 8px，最终取向待确认（审计 §C6 分歧标注）。
- **截图证据只覆盖五个页面**（课程表、课程地图、发布、设置、工作台编辑）；媒体库、制作看板、Flow / 自由排版、启动页等页面的整改只有代码与 CSS 证据，逐页截图**无记录**（审计 §0.1 / §E4）。
- **功能、交互流程与中文文案语义的改动不在本次范围**（红线：中文文案逐字保留、DOM 结构与类名不破坏）。
