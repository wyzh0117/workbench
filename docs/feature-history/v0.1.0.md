## 这个版本用户能做什么新事情？

这是 Workbench 第一次变成一个「普通用户下载、装好、就能开始写课程」的东西。装上之后你可以：

- **在一台 Mac 上完成一门课的整套创作**：课程地图看整门课的结构和完成度；单课编辑器管正文 / 结构 / 排版 / 预览；Flow 和 Grid 两种排版方式；素材库；待补总览；六维完成度。
- **让 AI 帮你改课，但它不会偷偷改**：AI 助手是「只审阅式」的——你可以选三种上下文范围（整门课程 / 当前课次 / 当前区块），调用之前能预览**将会发送什么、不会发送什么**；任何修改型请求会先生成一个 ChangeDraft，你逐条看 Diff、同意之后才 Apply。API Key 只写进 macOS 系统钥匙串，不回显，也不进入课程、备份、日志、导出或执行记录。
- **把课程交付出去**：发布与导出中心支持 Markdown（当前课 / 整门课程）、Semantic HTML、Static Web Package、PDF、微信 / 富文本迁移版、Project JSON、素材包、完整项目包。导出前的检查把问题分成 BLOCKING（必须处理）和 WARNING（可以确认继续），导出过程严格只读。
- **不用担心数据被弄坏**：原子写入、自动保存与恢复、项目锁、外部修改检测、历史版本恢复，以及**按项目分别保存的阅读位置**（换项目再换回来，不会串位）。
- **数据在你自己的磁盘上**：项目就是一份开放的 `project.json`，不是私有数据库。
- **Apple Silicon 和 Intel 用同一个安装包**（Universal 二进制）。

对课程作者来说，最关键的一点是：**这门课的唯一真相只有一个文件**，AI 和导出都不制造第二份内容。

## 哪些操作方式发生了变化？

**无记录**（相对更早版本）。`v0.1.0` 是第一个公开版本，之前没有公开可下载的版本，因此不存在「用户原来怎么做、现在改成怎么做」的历史。

有两件事对**所有**用户都是全新的操作，值得单独说明：

1. **首次打开必须手动放行一次。** 这一版没有用 Apple Developer ID 签名，也没有做公证，所以 macOS 第一次打开时会拦下来，提示「无法验证开发者」或「Apple 无法检查其是否包含恶意软件」——这是预期行为，不是安装包坏了。放行只需要做一次，方式取决于系统版本：
   - **macOS 15 (Sequoia) / 26 及更新版本**：双击后在拦截框点「完成」→ 打开「系统设置 → 隐私与安全性」→ 在「安全性」区域找到「已阻止使用 AI Course Workbench…」→ 点「仍要打开」→ 输入密码或 Touch ID → 在再次出现的确认框里再点一次「仍要打开」。（Apple 已经取消了「右键 → 打开」这条捷径，Control-click 不再能绕过 Gatekeeper。）
   - **macOS 11 (Big Sur) – 14 (Sonoma)**：在「应用程序」里右键（或按住 Control 点击）App → 选「打开」→ 在弹窗里再点「打开」。
   - 本项目**不指导、也不建议**关闭 Gatekeeper 或用 `xattr` 移除隔离属性。
2. **下载入口是固定的。** 安装包文件名在所有版本中都保持不变（`AI-Course-Workbench-macOS.dmg`），所以 `https://github.com/wyzh0117/workbench/releases/latest/download/AI-Course-Workbench-macOS.dmg` 这条直链会长期指向最新版，不用记版本号。校验方式：`shasum -a 256 ~/Downloads/AI-Course-Workbench-macOS.dmg`。

## 兼容性或迁移变化

没有需要迁移的旧版本（这是第一个版本）。这一版确立了后续所有版本沿用的约定：

- 系统要求：**macOS 11.0（Big Sur）或更高**；架构 Universal。
- 分发格式只有 DMG：**没有** PKG、Homebrew Cask、Mac App Store、自定义安装器，也**没有**自动更新器。升级 = 重新下载新版 DMG 覆盖安装。
- 项目数据格式：磁盘上的开放 `project.json`（Canonical 真相）；`.workspace` 是可重建的本地状态；`project.bak` 是备份产物，不是项目合法性的必要条件。
- 固定安装包文件名 + 固定 `latest` 直链 + `.sha256` sidecar（见上一节）。

## 已知限制

这一版如实记录了以下限制，写在 Release 正文里的原话状态：

- **尚未完成真实在线 AI Provider 调用验收。** 本版走通完整闭环用的是离线的「本地确定性连接器」。真实 Provider 的请求组装、鉴权注入与错误码映射有自动化测试覆盖，但**没有一次真实在线 smoke**。
- **未签名、未公证。** 发版机器上没有可用的 Apple Developer Program 分发凭据（`security find-identity -v -p codesigning` 返回 0 valid identities），因此 DMG 为 **ad-hoc 签名**：`codesign --verify --deep --strict` 通过，但 `spctl --assess --type execute` 判定 **rejected**。分发状态因此记为 `PARTIAL / BLOCKER = 缺正式 macOS signing / notarization credentials`，**不宣称** `PUBLIC RELEASE READY`，也**不宣称**「普通用户无安全阻碍安装」。
- **放行之后的首次启动未实测。** 只实测了放行**之前**的拦截状态（把 Release 资产重新匿名下载、按浏览器行为加上隔离属性后 `spctl` 判 `rejected`）；放行之后的那一次启动没有实测过，因为自动化环境无法投递右键菜单与「系统设置」的交互。
- **PNG / JPG 位图输出与复杂长图海报系统为明确的非目标。**
- **Windows / Linux 不在本版支持范围内。**
- **仓库可见性曾经波动过**（`PROJECT_MASTER_CONTROL.md` §34 补充记录）：2026-09-24 仓库按用户要求改回 PRIVATE，`v0.1.0` 的 Release 页面与 `latest` 直链对匿名访问者返回 404，公开下载临时下架（Release 与资产保留在仓库内、未删除）；2026-09-25 仓库重新设为 PUBLIC，公开下载恢复。
