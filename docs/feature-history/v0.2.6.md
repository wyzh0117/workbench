## 这个版本用户能做什么新事情？

- **Mapping Preview 更稳定、更专注。** 它只显示根级映射对象与目标；勾选不触发其他行的重扫或重解析，反复打开不会把选择错配到另一行。Mapping 不再混入图片依赖、正文导入结果和建议栏。
- **在映射确认后逐份选文档。** 对已勾选根级文件夹的直接子文档，可在分组弹窗中全选、清空、勾选或点整行选择；媒体仍递归进入素材库而不自动插入正文。文档候选仍服从已经确认的目标映射。
- **正文导入保留文档结构和可解析图片位置。** Markdown、DOCX、EPUB 和 LaTeX 的安全、可解析图片会进入素材库并关联语义区块；只由递归媒体扫描发现的文件不会凭空生成正文引用。
- **在 Preview 阅读带图片、GIF 和视频的正文。** 图片直接显示；GIF 首次显示静态首帧，打开媒体查看器后由用户播放；视频先展示首帧，打开后保持暂停，点击播放才播放。关闭时停止并复位媒体。
- **用 Flow 查看和调整正文顺序。** 点击一行回到正文的同一区块；拖动把手更改唯一的 Canonical 区块顺序，并同步到 Preview 与导出。
- **从独立的「自由排版」编辑 Grid / Page。** 原工作台内「结构」和「排版」入口移除；网格落位、跨页、页面管理、尺寸调整、导出投影继续保留。
- **全局页面与弹窗共用视觉规则。** 本轮逐页审计及仍需核实的视口 / 无障碍状态见 [UI audit](../reports/v0.2.6-ui-audit.md) 与 [设计系统](../reports/v0.2.6-design-system.md)。本说明不声称达到奖项标准。

## 哪些操作方式发生了变化？

- Mapping 确认根级对象和目标后，文档候选才会进入二次选择；二次弹窗只读被选文件夹的直接子文档。新的 lesson-folder 分组由后端从已确认的父目录映射与重验路径推导；目标已存在的课时保持追加语义。
- 工作台的视图为「正文 / Flow / Preview」。正文是编辑表面，Flow 用来读结构和改顺序，Preview 用来阅读结果。
- Grid/Page 从工作台移入主导航「自由排版」。

## 哪些旧问题被修复？

- Mapping 勾选抖动、点一行使其他行重读、反复打开错位，有相应的定向回归。
- 课程文件在其他地方发生变化时，保存会暂停以避免覆盖；用户可以重新载入、合并或在有实际冲突时明确保留本地版本。重复导入保护也保留已有编辑，不静默替换正文。
- Flow 行点击跳转到正文，排序拖动通过 drag handle 更新 canonical order。
- 多个被选 lesson-folder 直接子文档在新 Lesson 目标下错误拆分的问题已修复：同一父文件夹下的被选文档共享一个文件夹名 Lesson；未选第三份保持不导入。
- 详见 [格式与后端证据](../reports/evidence/v0.2.6/mapping-backend.md) 和 [Deno gate 记录](../reports/evidence/v0.2.6/deno-gates.md)。

## 兼容性或迁移变化

- `project.json` 保持 Canonical。Flow 写既有 block 顺序；Free Layout 继续使用已有 layout、placement 与 page 模型。
- 旧 Workbench Layout route 迁移到 Free Layout，既有 Grid/Page 数据和 PDF/PPTX/HTML/Web projection 继续保留。
- 导入不移动、不重命名、不覆盖源文件；递归发现的媒体只进素材库，只有语义文档节点会建立 `AssetUsage`。

## 已知限制

- `.txt/.text` 只有文本，不能承载有语义的图片位置。PDF 只抽取文本层；不提取 image XObject，不做扫描件 OCR，也不伪造图片顺序。
- LaTeX `\\graphicspath`、旧 `epsfig` / `psfig` 等不支持；不支持的宏、环境和数学表达按 warning 降级。EPUB CSS 不会变成正文格式，DOCX 不保留 Word 视觉主题或完整版式。
- 最新 1280×720 browser CUA 已验证导入 Markdown 的 heading、inline emphasis、quote、semantic list、PNG 与 GIF；Preview 会提示 `![alt](clip.mp4)` 属于不支持的视频图片语法，应从 Media 插入视频 block。真实视频 block 的 poster、默认暂停、显式播放、时间推进和关闭复位，以及 GIF viewer 动画和静态 inline 首帧均已观察。Body 按键输入两行 dash list 并 blur 后得到 semantic list；未编辑的 escaped 标记保持字面文本。
- Flow 真实拖动、Undo/Redo、Body/Preview 同序与保存重开磁盘顺序已通过 browser CUA。重开后顶栏误显「未保存」的问题已修正；最终全量 Deno gate 602/602，UI owner 的 run6 reload 显示「已保存」。Free Layout 的跨页目标面板曾报 `ReferenceError: pageGrid is not defined`；缺失导入已修，定向渲染测试 66/66 PASS，browser CUA 复测跨页移动、跨度调整、新建页和复制页并确认 placement 持久化。删除没有实际执行；重开/导出仍待验收。Overview/shared shell 在 1024、1280、1440、1728×900 测量无横向溢出或顶栏重叠；其余路由、侧栏组合、系统 text scale 和完整 overlay 键盘检查见 HTML completion report。本机 CUA 返回锁屏且自动解锁失败，native-app smoke 为 BLOCKED；截图二进制无法通过当前 CUA 接口保存，报告只记录真实观察而不伪造图片。
- 当前公共下载和 `releases/latest` 仍是 v0.2.5。最终冻结源码的本地 Universal candidate 已构建并通过 `hdiutil verify`、版本/架构/挂载内容检查（0.2.6、`x86_64 arm64`；SHA-256 `c4594037e0c9d4e908c9896e2aff9b39c55b23c883e19c0429fb73654d2e354f`）。本地候选无 Developer ID 签名/公证，native smoke 未执行；公开 workflow 与资产须发布后单独核验。
