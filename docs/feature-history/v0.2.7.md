## What users can do

- Keep project saves and recovery decisions tied to the active project and disk revision. External edits pause conflicting saves instead of being silently overwritten.
- Preview a non-conflicting merge or explicitly keep local edits when merge preview cannot apply; the external version is preserved in the pre-write backup.
- Reopen at the saved reader viewport, view legacy snapshot timestamps, and rename referenced media with Undo/Redo while its usage and physical path remain aligned.
- See per-item media preview errors without blocking valid neighboring items, and navigate the final Board lane with keyboard horizontal scrolling.
- Export a representative paged lesson to Semantic HTML, Static Web, PDF, and PPTX.

## Known limits

- Overall acceptance remains **PARTIAL**. The report maps IO-01–IO-10 and UI-01–UI-08 to the 27 P/O targets and evidence.
- The compound N06 flow is partial: the first-pointer Save Version after editing and referenced-asset Rename/Undo/Redo/Undo passed, but exact in-flight snapshot capture while editing and an A→B→A late-acknowledgement UI overlap were not observed.
- Diagnostics-on changed-save p95 was 21.12% above baseline in the final ten-sample paired run; the tail remains unexplained. No-op timing improved but does not cancel that limitation.
- Real 150%/200% text scaling and reduced-motion behavior were not run. WebKit-wide memory, decoded-image retention, and physical write amplification remain unmeasured.
- Export checks cover the named S01-01 fixture, not every course/layout combination. Actual signing and notarization status comes from the release workflow, not the local QA ZIP.
