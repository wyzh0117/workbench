## 这个版本用户能做什么新事情？

- **打开入口变成「项目列表」。** 应用记住每一个打开过的课程项目，按最近打开排序：点一下就能回到最近在用的那门课。文件夹被移动或删除的那一行会标明「找不到」，可以「重新定位」到新位置（只有 `project.id` 对得上才允许），也可以只把这一行从列表移除——都只动列表，不碰磁盘上的课程。
- **打开一个文件夹时不会认错项目。** 选中的目录里有可用的 `project.json` 就直接打开；内容属于旧版 schema 会先做一次结构修复再打开（`project.id` 原样保留）；文件坏掉、太新或者根本不是课程文件，提示会指出具体原因；目录里没有 `project.json` 时进入导入扫描。父目录下每个子目录各是一个项目时，父目录不会被当成其中任何一个（需要你自己选进哪一个）。
- **九类文本 / 文档可以直接接进正文。** `.txt` `.text` `.md` `.markdown` `.tex` `.latex` `.docx` `.epub` `.pdf` 都能作为课程正文导入，按文档原本的结构落位：标题层级、段落、加粗 / 斜体 / 删除线、引用、列表、代码、表格、链接、文档内嵌图片，不再是一整篇挤成一个纯文本块。
- **导入前可以逐份挑。** 映射确认之后，如果发现上面这些文档候选，会先列出「选择要导入为正文的文档」：全选 / 全不选 / 逐行勾选都有；媒体（图片 / 视频）不需要勾选，自动进素材库。
- **素材库滚动到底再往回滚不再闪屏。** 修好了「预览读完就整页重建 → 缓存把正在显示的缩略图挤掉 → 卡片退回等待加载 → 重新登记再读一次」的闭环：预览完成只更新那一张卡片，正在显示的卡片不会被淘汰，读不出来的卡片给出重试按钮而不是无限循环。120 张卡来回滚的自动化用例把每一步都钉住了。

## 哪些操作方式发生了变化？

- **映射确认之后多了一步「正文选择」。** 只有当映射范围内真的存在文档候选时才会出现；全部取消等于什么都不写入——媒体照常进素材库，课程内容保持原样，源文件仍在原处。
- **打开/启动入口以项目列表为主**（最近优先）；「打开普通文件夹走导入」的入口保持原样。
- **以前不会进正文的格式现在可以了**：`.txt` `.text` `.tex` `.latex` `.docx` `.epub` `.pdf`（`.md` / `.markdown` 此前已可以）。每份导入的文档都服从已确认的映射计划，不会在弹窗里另建一套阶段 / 课次推断。
- **扫描版 PDF 只作为参考文件保留**，并明确说明「没有可读取的文本层」，不假装导入正文。
- **LaTeX 数学公式以代码块形式保留**（公式源码不丢，导入结果标注为「有降级」并给出提示）。
- **非 UTF-8 的 `.txt`**（GB18030 / Big5 / windows-1252 等常见编码）会先识别编码再解析；识别不了就如实报错，不会用乱码凑出正文。

## 哪些旧问题被修复？

- **媒体库滚到底再往回滚时不断闪屏、UI 抽搐、其他地方点不动。** 根因是「预览读完就整页重建 → 缓存把正在显示的缩略图挤掉并作废图片地址 → 卡片退回等待加载 → 重新登记观察器再读一次」这个闭环。现在预览完成只更新那一张卡片、正在显示的卡片不会被淘汰、同一素材不会重复登记；120 张卡来回滚的自动化用例把每一步都钉住了。大白话根因说明见 [`../v0.2.5_media_flicker_root_cause.md`](../v0.2.5_media_flicker_root_cause.md)。

## 兼容性或迁移变化

- **旧项目打开时迁移不改身份：`project.id` 原样保留**，不产生第二个身份字段；迁移后直接通过完整性校验。
- **导入来源有记录**：权威清单在项目 `settings.markdown_import_sources`（来源相对路径 + SHA-256），首块上的 `markdown_import` 只是兼容副本；重复导入同一来源默认跳过，不会静默替换已编辑过的正文。
- **项目登记表是可重建索引**（桌面壳在应用数据目录、浏览器壳在项目根 `.workspace/projects.json`）：只存「哪个 id 在哪个路径、标题、最近打开时间」这类字段，不含课程正文、不含任何密钥；删掉它只会丢「最近打开」列表，课程本身不受影响。
- **来源文件保持原地**：不移动、不改名、不删除、不覆盖；导入只往里追加课程内容。

## 已知限制

- **扫描版 PDF 不做 OCR**：没有文本层时只保留参考文件并说明，本轮不引入 OCR。
- **PDF 只提取文本层**：不导入内嵌图片（位置与阅读顺序不可靠，按边界保留原 PDF 为来源引用）、表单字段与批注；不执行任何 PDF 脚本。多栏页面严格按「页序 + 内容流顺序」输出，不做坐标重排。
- **LaTeX 公式降级为代码**（源码保留 + 提示）；未知命令 / 环境按可读原文保留并聚合提示。
- **`.txt` 刻意不猜标题**：纯文本只按空行切段落，不根据全大写、行首符号猜结构。
- **EPUB 的 CSS 完全不解析**：只用 `class` / `epub:type` 名字做弱标题提示；字体、颜色、版式不进入课程。
- **DOCX 忽略** Word 主题、字体、字号、颜色、页边距、页眉页脚、文本框、WordArt（只保留有语义的标题、列表、表格、链接、图片等）。
- **媒体库闪烁修复的真实指针滚动**（滚轮 / 触控板来回滚、惯性反向）仍需真实窗口验证；原生窗口指针 / 面板手势与真实在线 AI 两条继承通道也仍未闭合（原因见 `v0.2.4.md` 的「已知限制」）。
