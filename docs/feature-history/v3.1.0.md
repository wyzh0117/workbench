## 这一版用户能做什么

- 从媒体栏或“发现素材”导入课程说明、课程大纲或教案。文档解析复用项目现有的导入素材与 canonical parser；桌面版支持 TXT、Markdown、DOCX、PDF、PPTX，浏览器壳只支持 TXT 和 Markdown。解析后可查看文件与正文状态。
- 配置模型和所需搜索 provider 后，可基于结构化主题和可追溯原文依据生成搜索意图并启动搜索；右侧候选渐进呈现。未配置服务时，解析结果仍保留并显示配置入口。
- 在“发现素材”“浏览器”“AI 助手”之间切换；安全读取 HTTPS 公网页面的纯文本，或打开原网页；显式选择将候选收藏到媒体库或插入课程。URL 去重、来源证据合并、重复采纳和任务恢复由现有资源工作流处理。
- 将右侧阅读区扩大或收回；窄屏右栏改为可关闭抽屉。布局检查涵盖 360px 等宽度，关闭和 Escape 后焦点返回右栏控制。
- 应用品牌标记和 Tauri 图标资产使用同一四格 SVG 母版。品牌主色为 `#14725f`，深色为 `#0d5b4c`；16、24、32、48、128、256、512、1024px 预览记录在[图标验收页](../acceptance/v3.1.0/icon-previews.md)。
- 工作台与设置等页面的 202 条草图文案建议均已映射到当前源码和行为测试；审计表记录了有意保留的凭据与授权边界文案。

## 兼容性与实现边界

- 课程项目的 canonical 数据 schema 未新增迁移。Reader tab、解析上下文和搜索意图作为有界 session/task metadata 保存；session validator 对字段、枚举和长度做白名单校验。
- 文档上下文只接受当前项目中已导入的 `asset_id`；主题依据必须匹配 parser 输出的 block/slide 和原文片段。任意本地路径不作为解析输入。
- 来源读取复用 HTTPS、公网地址解析与 pinned DNS、重定向拒绝、MIME、响应体上限和超时边界；远程 HTML 转纯文本，不在应用内执行脚本。
- 任务的 `completed_queries` 表示原始查询行的稳定完成前缀；停止/中断继续未执行行，失败任务只重试失败行，并保留已生成候选和来源。
- 没有新增大型图标库或新的运行时依赖。图标生成脚本使用已有本机工具链。
