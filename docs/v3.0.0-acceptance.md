## 发布建议

**当前没有已确认的 P0/P1 源码阻断；建议允许候选分支 push，并运行 `workflow_dispatch` build-only 验证发行包，不打 tag、不发 release。** 完整 Deno、Rust、fmt、`cargo tauri build --bundles app` 与同 CI identity 的严格 ad-hoc bundle 验证通过。本机首次未设 identity 的默认 sandbox `cargo tauri build` 因 `hdiutil: create failed - Device not configured` exit 1；按授权以 `APPLE_SIGNING_IDENTITY='-'` 执行 `cargo tauri build --bundles app,dmg` 后 exit 0，strict verify 与 DMG integrity 都通过。CI build-only 应继续验证 macOS universal DMG 和 Windows NSIS。曾发现的 PPT 输出目录同步和 pending marker 目录同步风险已修为“提交后显式警告并保留 marker 重试”与“marker 目录未同步则在写 output 前 fail-closed”，focused 故障注入测试通过。

**当前不满足 3.0.0 发布验收。** 规格 §9.6、§13 工作项 D 明确要求至少两份真实课件，并在真实 PowerPoint 打开、编辑、保存，核对 N/N+1/N+2、插入位置、无 Repair、对象可编辑和源文件 hash。只有一份真实课件 fixture；synthetic multi-layout 不是第二份真实课件。PowerPoint 临时副本启动后读取超时，Repair、页数、编辑与保存重开均无证据。真实 Brave/YouTube 查询没有凭据，按用户允许保留为 UNVERIFIED。UI 真文字缩放和真实大媒体库任务/连续编辑性能也没有闭合证据。
