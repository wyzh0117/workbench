4. Mapping 根因与修复

旧流程把行选择与衍生预览工作混在一起，切换一行可能重新生成无关建议或依赖信息，重开弹窗后选择也可能错位。现在扫描快照与本地选择分离；确认映射后才查找嵌套文档，关闭弹窗时会使过期扫描失效。执行层会重新验证直接子项路径，并根据已确认的映射推导课时分组，不采用客户端传来的分组字段。

课时文件夹边界：确认目标需要新建课时时，同一文件夹下选中的直接子文档会放入一个以文件夹命名的课时；目标为已有课时则追加到该课时；阶段文件夹下的子文档仍分别创建课时。未勾选的文档不会导入。课程文件在其他位置发生变化时，Workbench 会暂停保存并提供重载或合并；只有确有冲突时才允许明确保留本地内容。重复导入会保留已有编辑，不会静默覆盖。Deno/Rust 回归证据： mapping-backend.md 以及 deno-gates.md。

状态： 部分完成（PARTIAL） — 扫描、分组、路径信任边界、过期保存保护和持久化约定均通过；尚未在原生应用中观察完整的文档选择流程。

格式图片行为状态已知降级
.txt / .text纯文本没有可靠的内嵌图片结构，不会凭空创建图片引用。通过（PASS）只按段落拆分，不猜测标题或图片结构。
.md / .markdownGFM 本地图片引用在源路径安全且可解析时保留原位置与 alt 文本。通过（PASS）缺失引用会保留并显示警告；超出允许范围的路径会被拒绝。
.tex / .latex\\includegraphics 图片在安全解析后会保留在正文原位置，也支持最终仍位于根目录内的父级相对路径。通过（PASS）\\graphicspath 和旧式图形宏不会解析；数学内容和不支持的环境会降级并给出警告。

证据包括原生封装层实际接管、源文件与托管字节摘要值比对、语义用量位置、源顺序断言，以及关闭/重开后的持久性检查，详见 mapping-backend.md。
