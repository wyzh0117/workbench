4. Mapping Root Cause and Fix

The old flow mixed row selection with derived preview work, so toggling a row could rebuild unrelated suggestions/dependencies and reopen state could drift. The implementation separates a stable scan snapshot from local selection; nested document discovery occurs after confirmation, with stale scans invalidated when the dialog closes. The execution layer revalidates direct-child paths and derives lesson grouping from the confirmed mapping rather than client-supplied group fields.

Lesson-folder edge case: selected direct-child documents share one folder-named Lesson when their confirmed target needs a new Lesson; existing-Lesson targets append to that Lesson; stage-folder children remain separate Lesson records. Unchecked documents are excluded. When a course file changes elsewhere, Workbench pauses saving and offers reload or merge; it only offers keeping local work when there is a real conflict. Repeat imports preserve existing edits rather than silently replacing them. Deno/Rust regression evidence: mapping-backend.md and deno-gates.md.

Status: PARTIAL — scan, grouping, path trust, stale-save protection, and persistence contracts pass; the complete chooser flow has not been observed in the native app.
